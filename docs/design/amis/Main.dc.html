Pour qui est cette mémoire ?

Le mode règle la manière dont les personnes sont reliées et qui voit quoi. Les photos, albums privés, publics et partagés fonctionnent pareil dans les deux.

Ce choix fixe le mode par défaut de l'installation. L'administrateur pourra ensuite créer d'autres cercles, de l'un ou l'autre type (Administration › Cercles) ; chaque cercle garde son propre type.
